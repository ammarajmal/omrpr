# OMRPR Analysis Rules

## Reproducibility
- Every final table and figure must be generated by a committed script.
- Do not manually edit result CSV files.
- Raw data must stay in `omrpr_private_data/`.
- Processed summaries may be exported only if they do not expose private raw data.

## Figure Rules
- Save publication figures as PNG 300 dpi and PDF/SVG where possible.
- Save plotted numerical values as CSV where possible.
- Every figure script must state input files, output files, and claim-boundary dependency.

## Claim Safety
- All manuscript numbers must match `docs/claim_boundary.md`.
- Any claim containing "validated", "accurate", "synchronized", "real-time", "ground truth", or "torsion" must be checked manually.
