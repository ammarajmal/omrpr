# Project Structure

- `src/omrpr_analysis`: authoritative Python package
- `src/matlab`: MATLAB verification and engineering analysis
- `scripts/steps`: executable Step 00-12 entry points
- `configs`: reviewed scientific configuration
- `tests`: regression and constraint tests
- `docs`: methods, decisions, and acceptance criteria
- `data/*/source`: symlinks to external data tiers
- `outputs`: generated diagnostics and reports
- `manuscript/generated`: machine-generated manuscript artifacts
- `state/gates`: local reviewed stage approvals
